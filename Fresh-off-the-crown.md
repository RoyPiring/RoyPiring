⚙️ *Does this capability earn a place in how I actually work?*

---

## 🎯 What this is

A decision log with a build attached. The AI tooling landscape ships more real, interesting, genuinely good news than any working engineer can act on, and treating all of it as actionable is how staying current turns back into reading.

So every entry answers one question, and the build exists to make the answer honest. **A verdict formed by reading is a guess. A verdict formed by running is evidence.**

## 🔬 How a candidate earns a day

Two filters, and neither is a judgment call.

| Filter | The test |
|:---|:---|
| **The problem join** | Does it touch a friction that actually costs me something today? No match, no queue. |
| **The first-party test** | On the day it is picked, did the organization that published the news also ship the code, and does it run under a tool already paid for? |

The second filter comes from a measurement rather than a preference. When a specification's own organization ships the SDK, the median wait is **7 days**. When a build needs a third party to catch up, the median is **204 days**. So a candidate that fails is parked with the tool it waits on and a re-check date, which turns the backlog into a ranked queue instead of a pile.

## ⚖️ The output is a verdict

| | Means | Owes |
|:---|:---|:---|
| **ADOPT** | Going into the working system | The change actually made |
| **REJECT** | It is not | A reason specific enough not to re-litigate in six weeks |
| **WATCH** | Not yet, plausibly later | A re-check date that jumps the queue ahead of any news |
| **PARK** | Failed the first-party test | The tool it waits on, and a re-check date |

Every verdict carries a **reversal trigger**: the one line saying what would change the decision. A ledger of verdicts tracks tools. The frictions and the triggers track the engineer, and the friction list is the one that gets shorter.

## 📐 The rules that keep it honest

- **Research daily, build conditionally, 30 minutes as a cap and not a target.** Reading release notes every day is the habit. Only the build is earned.
- **A quiet day is a recorded outcome.** Nothing qualified, nothing shipped, and that row is a complete artifact. A quota against an event-driven source is how a dead-in-six-weeks toy enters by process rather than by taste.
- **No metered keys and no cards.** The practice runs on capability already paid for, so a daily habit never carries a daily cost.
- **A run to 100 logged verdicts.** The count moves only when a run actually happened, and it is never backfilled to protect a streak.

## 🗂️ The repo

[**`fresh-off-the-crown`**](https://github.com/RoyPiring/fresh-off-the-crown) holds the ledger and every entry behind it, each with its friction, its run record, its verdict, and its reversal trigger.
